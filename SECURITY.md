# Güvenlik

Bir güvenlik açığı bulursan lütfen herkese açık issue açma; GitHub'ın **Security → Report a vulnerability**
(özel güvenlik bildirimi) özelliğini kullan.

Her sürüm GitHub Actions üzerinde kaynak koddan derlenir, Windows Defender ve ClamAV ile taranır ve
`SHA256SUMS.txt` ile yayınlanır. Yalnızca bu deponun **Releases** sayfasından indirilen dosyalara güven.
